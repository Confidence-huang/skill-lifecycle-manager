# Security Policy

## Supported version

Security fixes target the latest release on `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue
for credentials exposure, path traversal, command injection, unsafe link handling, verification
bypass, rollback failure, or artifact/approval identity confusion.

Include the affected command, platform, version/commit, minimal reproduction, expected boundary,
and observed effect. Remove tokens, cookies, private keys, and personal paths from all evidence.

You should receive an acknowledgement within seven days. No service-level guarantee is implied.
